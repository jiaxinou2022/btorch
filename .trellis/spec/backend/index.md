# Btorch Development Guidelines

These specs describe the conventions used by the Python/Torch library in
`btorch/`. Read the relevant guide before changing package code.

| Guide | Scope |
|---|---|
| [Directory structure](directory-structure.md) | Package, tests, docs, examples |
| [Data storage](database-guidelines.md) | Tensor/DataFrame/file data |
| [Error handling](error-handling.md) | Validation and failure behavior |
| [Quality](quality-guidelines.md) | Torch-specific coding and verification |
| [Logging](logging-guidelines.md) | Library diagnostics and warnings |

The repository root `AGENTS.md` remains the authoritative short-form project
policy. These files provide task-scoped details and concrete examples.
